# example-plugin

Reference plugin for the `devdigest-plugins` marketplace.
It ships one skill, `plugin-authoring`, which tells Claude Code how plugins in this marketplace are laid out, named, versioned and released.

Copy this folder to start a new plugin, then replace the manifest, the skill and this README.

## Install

```
/plugin marketplace add mcmaxwell/devdigest-plugins
/plugin install example-plugin@devdigest-plugins
```
