## 0.1.0 - 2026-09-02

### Added

- `onion-architecture` skill: the dependency rule, layer map, ports and adapters through a DI container, transaction boundaries, dependency-cruiser enforcement, with references and an eval suite.
- `frontend-ui-architecture` skill: React and Next.js code organisation, colocation, view to hook to service layering, import boundaries.
- `engineering-insights` skill: the per-module `INSIGHTS.md` capture loop with its quality gates.
- `mermaid-diagram` skill: diagram type selection, syntax quick reference and templates.
- `security` skill: OWASP Top 10:2025 review guidance with checklists and unsafe/safe code pairs.
